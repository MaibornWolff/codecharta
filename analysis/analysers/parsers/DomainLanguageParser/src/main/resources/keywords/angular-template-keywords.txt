# Angular Template Keywords
# The words of Angular's template syntax that the identifiers of a template split into. Control flow keywords
# such as `@if` or `@for`, pipe names, `@defer` triggers and the keys and exported values of a structural directive
# (`trackBy`, `index`, `odd`) are not extracted as identifiers, so they need no entry and stay words of the text.
# One keyword per line. Entries are lowercased when loaded, so case here is cosmetic.

# Literals the grammar reads as identifiers
true
false
null
undefined

# The call of an output: (click)="selected.emit(creature)"
emit
