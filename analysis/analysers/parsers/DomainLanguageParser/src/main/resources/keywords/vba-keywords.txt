# Words of VBA and VB6 that name no domain: keywords, types and built-in names, the naming prefixes of Access code and
# the words of its event handlers. Keywords that are English words are listed as in the other languages, except
# `open` and `close`: Access code names its actions with them (`OpenInvoice`, `Form_Open`). Event words that also name a
# domain stay out as well (`report`, `current`, `change`, `key`).
# Names are split at capitals, so a keyword like `ByVal` comes out as `by` and `val`: both the whole word and its
# parts are listed, unless a part names a domain (`address` of `AddressOf`).
# One word per line. Entries are lowercased when loaded, so case here is cosmetic.
# Comments start with #
