Folders Card

A new Folders card in the metrics bar, shown only for the sunburst and radial treemap. It takes the slot the hidden Height card leaves. Two independent pickers: what number a folder shows, and whether folders are tinted by it or stay neutral. Files always keep their colour-metric colour.

Cog popover: folder style

Live: the same controls the cog opens in the bar. Tint strength runs from pale (20 %) to full colour (100 %).

Card states

Foldersmaxtinted 50 %
Foldersavg / linetinted 100 %
Foldersmaxneutral

Neutral keeps the chosen value visible but dimmed, so switching back restores it. The card only exists in the sunburst and radial treemap.

Behaviour

  • Clicking the card opens the value list; the cog opens folder style. Both open upward from the bar like the Color card.
  • The cog popover ends with Reset folder colors, like the other cards' reset buttons: back to max, tinted, 50 %.
  • Default: max, tinted at 50 %.
  • Tinted = the value's colour on the colour metric's thresholds and gradient mode, mixed toward white by the tint strength.
  • Neutral = one grey for all folders; picking a value switches back to tinted.
  • Hovering a folder shows its value in the tooltip, e.g. max 47.
  • The legend gets one line for folders (below).
