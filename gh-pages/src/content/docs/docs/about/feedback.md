---
title: "Feedback"
description: "Report a bug, ask for a feature or contribute to CodeCharta: how to reach the team through GitHub issues and where the contribution guide is."
---

Are you using CodeCharta and want to tell us what works and what does not? Is a use case missing that would make you
use it? Or do you want to contribute? We would like to hear from you.

We track every bug and enhancement as a [GitHub issue](https://github.com/MaibornWolff/codecharta/issues) and discuss
it in its comments. [Open an issue](https://github.com/MaibornWolff/codecharta/issues/new) for a bug, a feature request
or a question, or to say thank you.

To contribute code or documentation, read the
[contribution guide](https://github.com/MaibornWolff/codecharta/blob/main/dev_docs/CONTRIBUTING.md) first. The
[developer start guide](https://github.com/MaibornWolff/codecharta/blob/main/dev_docs/DEV_START_GUIDE.md) shows how to
build and test both parts.
